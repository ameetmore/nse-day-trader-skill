Option chain

Ask Claude: “get the NIFTY chain from Kite and save it”, or run chain.py symbols NIFTY --spot … and pass the list to Kite's get_quotes. The sample is synthetic.

Intraday equity size

Stops round down and targets round half up onto NSE's tick: ₹0.01 to ₹250, ₹0.05 to ₹1,000, ₹0.10 to ₹5,000, ₹0.50 to ₹10,000, ₹1 to ₹20,000, ₹5 above.

Weekly expiries

A holiday moves the expiry to the trading day before. The last expiry of the month is the monthly contract. NSE 2026 holiday list built in.

Run the pack

The analysis runs in Python on your computer (3.8 or newer, nothing to install), and in Claude Code as 16 skills. Code: github.com/ameetmore/nse-day-trader-skill.

Windows

git clone https://github.com/ameetmore/nse-day-trader-skill.git
cd nse-day-trader-skill
py -m unittest discover -s tests
mkdir trader
copy nse-budget\config.example.json trader\config.json

An intraday NIFTY option buy

py nse-entry\entry.py check ^NSEI --write
py nse-fno-chain\chain.py symbols NIFTY --spot 25793
  (Claude: Kite get_quotes with that list, saved to trader\fno\quotes-NIFTY.json)
py nse-fno-chain\chain.py analyse NIFTY --quotes trader\fno\quotes-NIFTY.json --spot 25793 --write
py nse-fno-plan\plan.py --write
py nse-risk\check.py
py nse-broker\ticket.py show

In Claude Code

/plugin marketplace add ameetmore/nse-day-trader-skill
/plugin install nse-day-trader-skill@nse-day-trader-skill

Then ask: /nse-research RELIANCE, /nse-scanner, /nse-fno-chain NIFTY, /nse-journal score. Options stay off until "allow_options": true in trader/config.json, and every order needs nse-risk's PASS and your typed yes.

Built on the pack's own rules: NSE 2026 holidays, NIFTY lot 65 (Tue), SENSEX lot 20 (Thu), option tick ₹0.05, Zerodha charges with STT 0.15% on option sales from 1 April 2026. Exchanges revise lots and limits: check before trading. Education and tooling, not investment advice.
